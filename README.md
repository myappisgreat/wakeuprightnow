# 醒醒 · Wake Up Right Now

繁體中文 PWA 鬧鐘。響鈴後必須答對 5 題隨機兩位數加法（10～99 + 10～99）才能停止。答錯可重試，不扣除進度。

## 本機使用

在此資料夾執行 `python -m http.server 8080`，開啟 http://localhost:8080。請勿直接以 file:// 開啟。

設定時間後，鬧鐘排在下一個該時間，設定會儲存在本機。可按「試響與練習」測試音量和完整答題流程。支援的瀏覽器會顯示「安裝 App」；iPhone 可從 Safari 分享選單選擇「加入主畫面」。首次載入成功後，核心功能可離線使用。

## GitHub Pages

這是無建置步驟的靜態網站。在 GitHub 儲存庫 Settings → Pages，選擇從分支部署，使用本專案所在分支的根目錄。發布網址須使用 HTTPS，PWA 和 Service Worker 才能正常運作。所有資源採用相對路徑，支援儲存庫子路徑。

## 瀏覽器限制

請保持 App 開啟、螢幕亮著，並確認音量。設定鬧鐘後會嘗試使用 Screen Wake Lock；支援度由裝置決定。背景分頁、鎖屏、關閉 App、裝置休眠時，瀏覽器不能保證準時響鈴。重新開啟時，已過期且未完成的鬧鐘會再次進入答題流程；若音訊被瀏覽器阻擋，可點「恢復鈴聲」。這不是原生系統鬧鐘。

字型線上可使用 Noto Sans TC，離線自動使用裝置字型。無追蹤、無後端、無外部 JavaScript 依賴。
